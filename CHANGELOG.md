# Журнал изменений Pulse CRM

Здесь фиксируются заметные пользовательские, эксплуатационные и совместимые с
API изменения. Production-реквизиты, реальные домены и секреты в журнал не
включаются.

## Unreleased — 29 августа 2026 года

### Добавлено

- Управление воронками: создание и переименование воронки, добавление рабочего
  этапа, изменение названия и цвета этапа.
- Безопасное удаление неиспользуемого рабочего этапа и не последней
  неиспользуемой воронки с проверкой связанных сделок и настроек.
- Optimistic locking для операций настройки воронок и понятные ответы HTTP 409
  при конфликте версии или наличии зависимостей.
- Иллюстрированное Markdown-руководство пользователя и обновлённое руководство
  администратора.

### Исправлено

- Этапы amoCRM идентифицируются парой `pipeline_id:status_id`. Одинаковые
  системные status ID в разных воронках больше не считаются дублями, а сделки
  связываются с этапом своей воронки.
- Сохранена совместимость с ранее созданными сопоставлениями этапов по одному
  status ID; повторный импорт остаётся идемпотентным.
- Alembic не предлагает удалить PostgreSQL GIN-индексы полнотекстового поиска,
  которыми управляет явная миграция.
- Backend CI разделяет окружение проверки PostgreSQL-миграций и изолированных
  тестов приложения.

### Документация

- Состав импорта amoCRM явно включает воронки, этапы, пользователей, поля,
  компании, контакты, сделки, открытые задачи и обычные заметки.
- Инструкции развёртывания обезличены: используются только плейсхолдеры без
  параметров конкретного production-контура.
